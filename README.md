Env-Guard is a developer tool designed to detect environment configuration drift before it becomes a production problem. 

🔍 𝗪𝗵𝗮𝘁 𝗱𝗼𝗲𝘀 𝗘𝗻𝘃-𝗚𝘂𝗮𝗿𝗱 𝗱𝗼? 
It scans your codebase, detects environment variable usage, and compares those references against your environment configuration files.
